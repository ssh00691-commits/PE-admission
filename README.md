# PE-ON 사용설명서

## 1. 바로 실행하기
1. 폴더 안의 `index.html`을 더블클릭합니다.
2. Chrome, Edge, Safari, Firefox 등 최신 브라우저에서 설치 없이 실행됩니다.
3. 인터넷 연결이 없어도 검색·비교·편집·CSV 기능은 작동합니다. 공식 출처 링크를 열 때만 인터넷이 필요합니다.

## 2. 주요 기능
- **대학 찾기**: 대학명·지역·학년도·수시/정시·실기종목으로 필터링합니다.
- **3개교 비교**: 각 카드의 **비교 담기**를 눌러 최대 3개 전형을 비교합니다.
- **비율 그래프**: 내신·수능·면접·실기·기타 반영비율을 색상 막대로 표시합니다.
- **연도별 변화**: 공식 자료로 교차 확인한 2024~2027 변경사항만 표시합니다.
- **CSV 다운로드**: 현재 전체 데이터가 엑셀 호환 UTF-8 CSV로 저장됩니다.
- **PDF 인쇄**: 브라우저 인쇄 창에서 대상 프린터를 **PDF로 저장**으로 선택합니다.

## 3. 교사용 자료 수정
1. **교사용 편집** 메뉴에서 필수 항목을 입력합니다.
2. 반영비율 합계를 100%로 맞춥니다.
3. 실기종목은 `종목명:배점` 형식으로 입력하고 쉼표로 구분합니다. 배점이 공식 문서에 없으면 `종목명`만 입력합니다.
4. 반드시 대학 입학처의 공식 URL, 자료명, 확인일을 입력합니다.
5. 검증 확인란을 체크하고 저장합니다.

수정 데이터는 브라우저 `localStorage`에만 저장됩니다. 브라우저 데이터 삭제 시 사라질 수 있으므로 **JSON 내보내기**로 정기 백업하세요.

## 4. 다른 교사·학생과 공유
- 교사: 교사용 편집에서 **JSON 내보내기**를 누릅니다.
- 학생/다른 교사: **JSON 가져오기**에서 받은 파일을 선택합니다.
- 프로그램 폴더 전체를 압축해 공유하면 동일한 오프라인 앱을 사용할 수 있습니다.

## 5. 공식자료 원칙
- 2027학년도 자료를 우선합니다.
- 공식 문서에서 확인하지 못한 수치·종목은 빈 값 또는 ‘미확인’으로 표시합니다.
- 카드와 상세 화면의 출처 링크·확인일을 통해 원문을 다시 확인할 수 있습니다.
- 시행계획은 변경될 수 있으므로 원서접수 전 최종 모집요강을 반드시 확인하세요.

## 6. 데이터베이스 연결 구조
현재 `app.js`의 `StorageAdapter`가 로컬 저장을 담당합니다. 향후 공동 편집 서버를 붙일 때 이 객체를 REST API, Firebase 또는 Supabase 어댑터로 교체하면 됩니다.

권장 서버 구조:
- `universities`: 대학 기본정보
- `admission_tracks`: 학년도/모집시기/전형별 반영비율
- `practical_events`: 실기종목·배점
- `sources`: 공식 URL·확인일·검증자
- `change_history`: 연도별 변경 이력
- 사용자 권한: 학생(읽기), 교사(수정 제안), 관리자(검증·게시)

## 7. 파일 구성
- `index.html`: 화면 구조
- `styles.css`: PC·모바일 반응형 디자인과 인쇄 스타일
- `app.js`: 검색, 비교, 편집, 내보내기 기능
- `data/data.js`: 더블클릭 실행용 내장 데이터
- `data/universities.json`: 데이터 교환·DB 적재용 JSON
- `data/schema.json`: JSON 필드 정의

## 8. 현재 데이터 범위
이 배포본은 2026-10-30 기준, 공식 입학처 문서에서 세부 수치를 직접 확인한 레코드만 포함합니다. ‘전국’은 검색·추가 가능한 시스템 범위를 뜻하며, 검증되지 않은 대학 데이터를 채우기 위해 임의 값을 생성하지 않았습니다.
